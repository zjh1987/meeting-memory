跨会议关联

关联完全在服务器本地完成：只回看同项目历史会议的议题与未闭环待办， 按时间范围与关键词匹配，不调用大模型，因此不会增加任何 API 费用。

只关联该时间范围内的会议；0 表示不限时间。
最近 N 场始终参考；更早的会议仅在命中关键词时纳入。
越低越容易判定为“议题重复”，默认 0.6。
越低越容易把待办视为已跟进，默认 0.5。
每行一组同义词，用逗号或顿号分隔。当历史会议和本次会议命中同一组词时， 即使字面差异较大也会建立关联；该提示词只参与本地匹配，不会发送给大模型。
