重置密码

出于安全考虑，系统不通过网页自助重置密码。

普通成员

请联系管理员，在管理后台「权限」页为你重置密码。重置后旧登录状态会立即失效。

管理员忘记密码

登录部署服务器，在项目目录执行以下命令，按提示输入新密码： 

python deploy/reset_password.py admin

也可指定账号：python deploy/reset_password.py <账号>。 该命令会同时让此账号的所有已登录会话失效。
